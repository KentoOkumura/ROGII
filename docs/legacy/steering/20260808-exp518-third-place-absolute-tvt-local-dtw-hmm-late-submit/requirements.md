# 要件

## 依頼と手法契約

- 依頼原文: exp515の再現失敗理由を説明した後の「それでは修正してください」。
- 期待する成果: exp515で正解を十分に表せなかったTVT候補範囲を廃止し、3位解法の公開説明にあるTVT位置を状態として扱う。Local-DTWも井戸全体で固定した伸縮率ではなく、区間ごとに参照位置を調整できる処理へ置き換える。
- 一次資料 / 参照実装: Kaggle Discussion `733319`（tereka, `3rd Place Solution`）、exp209/exp374の絶対TVT HMM、失敗したexp515。
- input: horizontal wellの`MD, Z, GR, TVT_input`、対応typewellの`TVT, GR`、検証対象の坑井を除いて作る兄弟井のGR参照波形、正解TVTを使わずに保存したexp374予測。
- target / objective: 学習損失なし。未知区間の正解`TVT`は予測内容を確定した後だけ結合し、行単位のRMSEを計算する。
- output: 各未知行のTVT事後平均。base、Local-DTW、fine-binを公開比率`0.50 / 0.20 / 0.30`で混合し、地層の傾きと累積補正量を制限する。
- GRの尤度: Student-t分布、自由度1。
- 推論: `(TVT位置, 地層の傾き, GRのずれ, 参照波形)`の組み合わせについてforward-backwardを計算し、TVTの事後平均を出す。Local-DTWでは参照位置の小さなずれを行方向に変化させる。
- 処理単位: 1坑井。最後の既知128行と未知区間を一続きで処理し、初期の地層の傾きは最後の既知256行から推定する。
- 実装区分: 近似実装。元コード、TVTの刻み、遷移確率、GRのずれの刻み、self-referenceの重み、Local-DTWの詳細が非公開である。
- 追加近似: 正解を使わずに保存したexp374予測をTVT候補の中心にし、その標準偏差から中心に近い位置を優先する。これは公開説明にない。
- 検証できない主張: 元コードとの一致、非公開parameterの一致、原チームのfold assignment、公開OOF `5.9703`の厳密な同値再現。
- ユーザー承認: 2026-08-08、未公開部分を推測した近似実装であることを説明した後、ユーザーが修正を依頼した。

## 制約

- 新しい実験`exp518`で実施し、失敗したexp515を上書きしない。
- 乱数なし、坑井・fold・3種類・状態の順序を固定し、設定と予測内容のSHAを記録する。
- validation foldの全坑井を兄弟井の参照波形作成から除外する。
- 未知区間の正解TVTは、予測内容のSHAを確定した後だけ読む。
- Public LBで状態範囲、遷移確率、混合比を選ばない。
- 小規模確認が3位の公開OOFから大きく離れる場合、全件学習、推論、提出へ進まない。
- Notebookと記録には、コンペ終了後の`LATE SUBMIT`候補であることを明記する。

## 受け入れ基準

- 上記の入力、出力、尤度、推論、処理単位がコードと一致する。
- 近似箇所と検証不能な主張を記録する。
- TVT候補範囲外の正解行数と、範囲だけによる最小RMSEを診断として記録する。
- Local-DTWで、参照位置のずれが行方向に変化できる。
- 3種類、prefix 128、初期値256、参照波形のbin幅`0.25 / 0.0625 ft`、Student-t自由度1、固定混合比、後処理の検査が通る。
- 有限値、重複ID、事後確率の正規化、参照元からの検証坑井除外を確認する。
- 再現判定前に推論を実行しない。再現未達なら推論用ファイルは停止理由を表示して終了する。
- gzip予測は展開後内容のSHAを主な証拠として記録する。
