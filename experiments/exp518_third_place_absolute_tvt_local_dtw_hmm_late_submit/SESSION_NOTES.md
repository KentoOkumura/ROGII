# exp518 セッションノート

## 目的

exp515で正解TVTを十分に表せなかった位置の持ち方と、井戸全体で固定したLocal-DTWの近似を修正する。3位チームの公開OOF `5.9703`へ達した場合だけ推論の実施を検討する。

## 一次資料の再確認

- Kaggle Discussion `733319`（tereka, `3rd Place Solution`）を2026-08-08に再取得した。
- 公開説明には、TVT位置、地層の傾き、緩やかに変化するGRのずれ、参照波形の選択を隠れ状態にすることが記載されている。
- base / Local-DTW / fine-binの比率は`0.50 / 0.20 / 0.30`、GRの尤度はStudent-t分布の自由度1、推論はforward-backwardによる事後平均である。
- 著者2名の公開Notebookとコンペ内の`3rd place` Notebookを検索したが、元コードは見つからなかった。状態の数値範囲、遷移確率、Local-DTWの詳細は依然として不明である。

## exp515の問題と修正

- exp515は最後の既知256行から得た傾きを直線延長し、その周囲`±10 ft`だけをTVT候補にした。この範囲から正解TVTが外れる行は60.75%あり、範囲内の最良値を選んでもRMSEは38.40だった。
- exp518では、正解TVTを入力せずに作成したexp374の絶対TVT予測を各行の中心にし、`-60`から`+60 ft`を`1 ft`間隔で候補にした。
- 学習773坑井でexp374予測から60 ft以上外れる正解は0.371%で、この範囲だけによる最小誤差はRMSE 0.806である。10坑井の動作確認では範囲外の行は0だった。
- exp374予測の標準偏差から位置の事前確率を作り、標準偏差の下限を10 ftとした。この処理は計算を安定させるための追加近似で、3位チームの公開説明にはない。
- Local-DTWは参照TVTのずれ`-2 / 0 / +2 ft`を状態とし、隣接するずれへだけ遷移できるようにした。これにより対応位置は行ごとに変化できる。
- Numba関数は坑井の並列処理を始める前に一度実行し、複数スレッドによる同時コンパイルを避けた。

## ローカルでの確認

- 対象: 並べた773坑井から等間隔に選んだ10坑井、43,556未知行。
- 設定: 3種類を各坑井1回、合計30回。位置は`±60 ft`、`1 ft`間隔。外側の坑井処理2並列、Numba 2 threads。
- 混合後RMSE: `11.12147398755525`。
- exp374予測のみの同じ10坑井RMSE: `13.035597835960282`。
- 個別RMSE: base `11.104719214697239`、Local-DTW `10.976267862818439`、fine-bin `11.374637893769268`。
- 実行時間: HMM部分`454.6503秒`。
- 有限値、ID重複、3種類の重み、検証坑井の参照元からの除外、事後確率の正規化、正解TVTを読む時点を確認し、すべて通過した。
- 予測43,556行の展開後SHA256: `a3d2b7d7ea45f20df0eb11c7fbeaac28a630227bfe805c1dd0428bc35d9634a2`。

## 判定

10坑井だけの値は全773坑井OOFではないため、正式なCVとして扱わない。3位チームの公開OOFとの差は`5.1512`あり、修正後も小規模確認の時点で再現水準に達していない。全773坑井のKaggle学習は開始せず、推論Notebookは実行不能な停止用ファイルへ置き換え、提出ファイルも生成しない。

残る主な不確実性は、参照する兄弟井の選び方、self-referenceの重み、状態の刻みと遷移確率、Local-DTWの具体的な計算である。公開情報だけでは原実装との一致を確認できない。
