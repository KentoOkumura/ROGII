# exp518 3位チームのHMM公開説明に基づく修正版

## 状態

完了（再現未達）。既知の実装上の問題を修正し、ローカルで10坑井の動作確認を完了した。RMSEは`11.1215`で、3位チームの公開OOF `5.9703`を再現できなかった。全773坑井のOOF、推論、提出は実行していない。

この実験はコンペ終了後の`LATE SUBMIT`候補として作成したが、再現未達時は推論へ進まないというユーザー指示に従い、提出せず2026-08-08に終了した。

## 仮説

exp515の主な問題は、TVT候補の範囲が狭く正解を表せなかったことと、Local-DTWを井戸全体で固定した伸縮率に置き換えたことだった。TVT位置を各行で十分に動かし、参照波形との対応位置も行方向に変化させれば、3位チームの公開OOFへ近づくと仮定した。

## 検証方針

検証対象の坑井を兄弟井の参照波形作成から除外し、予測内容を確定する前に未知区間の正解TVTを読まない。まず等間隔に選んだ10坑井で有限値、ID、事後確率、実行時間とRMSEを確認し、公開OOFから大きく離れる場合は全件学習と推論を停止する。

## 所見

- exp515の、最後の既知区間から延長した直線を中心とする狭いTVT範囲を廃止した。
- 正解TVTを使わずに作成済みのexp374予測を各行の中心とし、その周囲の絶対TVTを隠れ状態にした。
- Local-DTW（局所的に参照波形の対応位置を調整する処理）を、井戸全体で固定した伸縮率ではなく、行方向に変化できる参照位置のずれとして実装した。
- 検証坑井を参照波形の作成元から除外し、予測内容を確定する前に未知区間の正解TVTを読まないようにした。
- Numbaの計算関数を並列実行前に一度準備し、同時コンパイルによる失敗を防いだ。

修正後の10坑井RMSEは`11.1215`であり、公開OOF `5.9703`には届かなかった。位置候補の問題は解消したが、非公開の参照井選択、状態遷移、self-reference、Local-DTWの実装差が残っている。

## 注意

3位チームのコード、状態の刻み、遷移確率、Local-DTWの詳細は公開されていない。保存済みのexp374予測を中心に使う処理も公開解法そのものには書かれていないため、この実装は近似であり、忠実な再現ではない。

数値と停止判断の詳細は`result.md`を参照する。
