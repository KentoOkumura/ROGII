# Source-hidden idea portfolio v2 — top five

Allowed evidence: `rogii_source_hidden_packet_v1.md` only (cutoff 2026-07-12). The portfolio contains 12 staged, non-parameter-only cards; all learned decisions use nested whole-well validation, and every inference path must be offline, deterministic, dynamically enumerate hidden wells, align runtime sample IDs one-to-one, and fit inside nine hours.

1. **I01 — Joint tail increment distribution** (`exploration`, representation): replace rowwise points with a whole-suffix increment distribution and constrained decode. First test whether held-well E01 residuals contain predictable low-frequency structure; kill below 0.10 RMSE gain or on tail/runtime failure.
2. **I02 — Prefix-conditioned typewell calibration** (`safe`, information): use same-well prefix GR to define a reliability-bounded entity-specific reference, not a dense likelihood. Keep the global reference as an exact fallback; kill on weak held selectability, >10-ft worst-well regression, or >7.5-hour projection.
3. **I03 — OOF-error-matched corrupted-conditioning refiner** (`exploration`, data generation): reproduce candidate bias, autocorrelation, dropout, and rank inversion from outer-train OOF, pretrain correction under corruption, then fine-tune on real OOF conditioning. Kill on corruption mismatch, copy-through, or <0.10 held RMSE gain.
4. **I04 — Nested soft candidate posterior** (`orthogonal`, fusion/uncertainty): retain mass across existing, heatmap, and anchor candidates and abstain to E01. Report truth-bracketing coverage separately from nested target-free selector regret; kill if it captures <10% of the oracle gap.
5. **I10 — Parity-locked batched K-best engine** (`compute_enabler`): cache repeated observation terms and batch the exact recurrence to unlock global decoding/calibration. Require identical paths/scores, at least 3x bottleneck speedup, bounded memory, and an end-to-end downstream accuracy run below 7.5 hours.

Rejected up front: truth-aware oracle selection; direct heatmap rank-one/probability-weighted paths; another raw prefix-likelihood retune or dense switch; larger unpaired particle smoothing; and any train-only formation/public-example dependency. Missing inputs remain the hidden distributions of context length, overlap, GR missingness, and per-well runtime/memory, so they are stress axes rather than assumed constants.
